# AI Reflection — Javier (Inspection)

## How AI was used in this project?

AI was used in various ways in this project such as building the inspection module, the
backend API, etc. It also helped me fix a few bugs that I realised after the interim review
feedback. Additionally, it helped me with creating the tests as well as debugging. AI also
helped me cross-check against the rubric and submission guide to check whether I was on the
right track.

## Where AI added value?

Some areas where AI added value were when my app broke and had a Vite error saying it
couldn't find a file, but with the help of AI I was able to troubleshoot more efficiently
and find out the root cause of the error. If not for the AI, it would have taken way longer
to find alone. For example, the real cause turned out to be that the file originally lived
one folder shallower, and when it got moved into a deeper folder structure to match team
conventions, the import path didn't get updated. It also helped build a full working CRUD
feature model.

## Where I rejected or changed AI's first pass?

A moment where I rejected AI's first pass was during a prompt where I was told to run
`npm run seed`. I rejected it as it was going to wipe out Aeric's Scheduling data completely.
Instead of blindly following AI, I decided not to and worked my way around it instead, and
found a different solution.

## What I learned?

I have learned a lot of things during this project. For example, I learned to be more
specific when giving a prompt to AI, as it would make the process more efficient — if my
first prompt was more specific, I would not need to spend time re-prompting afterwards.
Another thing I learned was how important debugging as a process is. For example, my Vite
bug took several rounds of elimination, such as checking the file existed, checking for
duplicates, etc. It's not about guessing, it's about elimination. I also learned how
important team coordination is because of how the project is structured — each member has
to take their turn doing the project. As such, I learned to respect my teammates' time and
try not to keep each other waiting.
